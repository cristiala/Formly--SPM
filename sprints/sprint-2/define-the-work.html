Define the work

Break the project into assumptions, work packages, and the effort required to deliver it.

1. Assumptions

Assumption Why it drives cost Owner
Cross-platform codebase (iOS & Android) Building from a single shared codebase avoids duplicating frontend engineering hours. Technical Lead
Computer vision model processing handles real-time video feeds Requires specific technical infrastructure, higher computing, and optimization to process frames. Technical Lead
Core API and user account back-end run on cloud infrastructure Determines hosting, server scaling, and database storage tiers required to manage user data. Technical Lead/DevOps
Third-party integrations (payments) Every added external service introduces implementation complexity, testing overhead, and APIs. Integration lead
Fixed project duration and defined team capacity Sets the total labor footprint, project milestones, and resource allocation across sprints. Project Sponsor/Manager

Sprint 5

Refining the experience in Figma and turning the earlier hand-drawn concepts into a more polished, testable app flow.

Design iteration and prototype refinement

Figma Mockups

Review the complete Formly app flow from the Figma file: Welcome, Home, Form Check, Stored Exercises, PT Chat, Settings, and Profile.

01 / Welcome

Welcome screen

The Welcome screen is the first thing users see when they open the app. From here, they can log in with an existing account or sign up for a new one.

The walkthrough video shows the opening animation and the transition into the login and sign-up options.

Download Welcome video

01 / Home

Home screen

The Home screen helps users find an exercise, check camera setup, and return to recent or stored exercises. It shows the three most recent exercises and short summaries of saved feedback.

The bottom navigation keeps Stored, PT Chat, and Settings available from the Home screen.

Download Home mockup

02 / Form Check

Form Check and feedback screen

The Form Check screen pairs exercise playback with clear corrective feedback. Users can review cues, rate whether the feedback helped, add a comment, and save the feedback with the video.

The side-by-side layout keeps the movement and its coaching cues visible together.

Download Form Check mockup

03 / Stored

Stored Exercises screen

The Stored Exercises screen gives users a searchable, date-sorted history of saved sessions. Each row shows the exercise, date, saved-feedback status, and a path to the full result.

Users can also upload exercises from this screen.

Download Stored Exercises mockup

04 / PT Chat

PT Chat screen

The PT Chat screen supports a live coaching session with the trainer, a tracked preview of the user's movement, and camera, microphone, and call controls.

Pose-analysis playback, session recording, and notes remain available below the call.

Download PT Chat mockup

05 / Settings

Settings screen

The Settings screen groups profile access, AI feedback preferences, and account and security controls. The profile card leads to profile editing; the other rows lead to their matching settings.

The same four bottom destinations appear here, with Settings highlighted to show the current page.

Download Settings mockup

06 / Profile

Profile screen

The Profile screen lets users maintain the information Formly needs to personalize coaching, including contact details, fitness goals, nutrition preferences, experience, and accessibility needs.

A clear return path takes the user back to Settings without losing the main bottom navigation.

Download Profile mockup
